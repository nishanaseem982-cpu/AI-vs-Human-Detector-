# AI vs Human Detector

This project is an AI vs Human Detector that identifies whether a given text or input is generated by an Artificial Intelligence (AI) model or written by a human.

## Features
- Detects AI-generated content vs Human-written content.
- Uses a pre-trained machine learning model (`ai_human_model.pkl`).
- Web interface built using Python.

## How to Setup and Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd AI-vs-Human-Detector
   ```

2. **Install the required packages:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the application:**
   ```bash
   python app.py
   ```
